# MusicMoodMatcher


Welcome to **Music Mood Matcher**, a web app that uses facial expression detection to suggest Bollywood Spotify playlists based on your mood! Built with love using JavaScript, `face-api.js`, and a sprinkle of creativity.

## Features
- **Real-Time Mood Detection**: Uses your webcam to detect emotions like happy, sad, angry, neutral, and surprised.
- **Bollywood Playlists**: Curates Spotify playlists tailored to your mood, featuring Bollywood hits.
- **Smooth Animations**: Enjoy fade-ins and bouncing Spotify links for a fun user experience.
- **Responsive Design**: Works seamlessly on desktop and mobile.

## How It Works
1. Click "Start Detection" and allow webcam access.
2. The app analyzes your facial expression every 0.5 seconds.
3. Based on your mood, it suggests a Bollywood Spotify playlist with a clickable link.

## Tech Stack
- **HTML/CSS/JavaScript**: Core web technologies.
- **face-api.js**: For facial expression recognition.
- **Spotify Links**: Embedded playlist URLs for instant listening.
- **VS Code + Live Server**: Development environment.
